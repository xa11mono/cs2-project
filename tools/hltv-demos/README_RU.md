# HLTV демки по картам / годам / tier

Скрипт открывает настоящий браузер, ищет на HLTV матчи с демками на нужных картах
за выбранные годы и нужного уровня, и сам качает их в твою папку.

## Установка (один раз)

```
pip install -r requirements.txt
python -m playwright install chromium
```

Для распаковки `.rar` поставь **7-Zip** (https://7-zip.org) — скрипт найдёт его сам.
Без 7-Zip архив просто останется целиком.

## Запуск

```
python hltv_demos.py
```

Скрипт спросит:
- **карты** — `mirage` или `mirage,inferno,nuke`
- **годы** — `2024`, `2022-2024` или `2021,2023`
- **tier** — `1` = 3-5★ (топ), `2` = 1-2★, `3` = 0★; можно `1,2`
- **папку** для демок
- **сколько матчей** скачать (0 = все)
- **лимит матчей с одного турнира** (0 = без лимита)
- **вытаскивать ли только нужные карты** из архива

То же самое аргументами:

```
python hltv_demos.py --maps mirage --years 2023-2024 --tiers 1 --out D:\demos --limit 50 --per-event 0 --extract yes
```

Подключиться к уже открытому Brave (как в остальных твоих парсерах):

```
brave.exe --remote-debugging-port=9222
python hltv_demos.py --cdp
```

## Как работает

1. Открывает `hltv.org/results?map=de_<карта>&content=demo&startDate=..&endDate=..` (только матчи с демками).
2. Фильтрует по звёздам матча (tier).
3. Заходит в матч, проверяет, что нужная карта реально сыграна (а не просто была в пике), жмёт **GOTV Demo**.
4. Из архива достаёт только `.dem` нужных карт (если включено) и кладёт в `<папка>/<год>/`.
5. Записывает ID матча в `<папка>/downloaded.json`.

**Повторов нет:** один матч = одно скачивание. Если в Bo3 сыграно две нужные карты
(например mirage и inferno), архив качается один раз и из него достаются обе карты.
При следующем запуске уже скачанные матчи пропускаются.

Если HLTV покажет проверку Cloudflare — пройди её в окне браузера, скрипт подождёт.
Остановить: `Ctrl+C`, прогресс сохраняется.
