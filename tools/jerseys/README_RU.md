# Автоматическая смена футболок игроков (v147)

Подсистема состоит из двух частей:

1. `js/media/jersey-swap.js` обнаруживает смену клуба, выбирает исходный портрет и показывает сгенерированную версию во всех местах, которые используют `HS.photoOf`.
2. Локальный Node-помощник в этой папке отправляет изображение в Hugging Face Inference Providers и записывает готовый файл в `assets/media/generated-jerseys/`.

Оригинальные фотографии не перезаписываются. В сохранении лежат только пути и метаданные. Очередь переживает перезапуск игры и временную недоступность помощника. Одновременно выполняется один запрос.

## Установка на Windows

1. Установите Node.js **20.11 или новее**: https://nodejs.org/
2. Откройте `tools/jerseys/` и запустите `start.bat`. При первом запуске помощник создаст `.env` и откроет его в Блокноте.
3. Создайте токен Hugging Face с разрешением **Inference Providers**: https://huggingface.co/settings/tokens
4. Вставьте токен в `.env` после `HF_TOKEN=`. Не добавляйте кавычки. Файл `.env` игнорируется Git.
5. Ещё раз запустите `start.bat`. Оставьте окно помощника открытым, пока игра генерирует портреты.
6. Откройте игру, перейдите в «Настройки» → «Автоматическая смена клубной формы», нажмите «Проверить помощник».

Если helper настроен, после следующего перехода игрока программа поставит портрет в очередь. Уже существующие составы не запускают массовую генерацию при первой загрузке. Для ручной генерации выберите команду и нажмите «Создать портреты текущей пятёрки».

## Провайдер и стоимость

По официальной таблице Hugging Face бесплатный аккаунт получает **$0.10 inference-кредитов в месяц** (сумма может меняться). Это не безлимитный API. Для редактирования портретов этих кредитов может хватить лишь на тест или несколько недорогих запросов; регулярная генерация может потребовать покупки дополнительных кредитов. Проверяйте тариф и стоимость до запуска очереди:
https://huggingface.co/docs/inference-providers/pricing

По умолчанию используется модель `black-forest-labs/FLUX.1-Kontext-dev`, которую Hugging Face относит к моделям для image-to-image редактирования. Клиент JavaScript — `@huggingface/inference` версии, зафиксированной в `package.json`.

Токен хранится только локально в `.env`. Он не передаётся браузеру, не записывается в сейв и не добавляется в репозиторий. Не вставляйте его в JS/HTML, не публикуйте скриншоты `.env` и не коммитьте этот файл.

## Настройка формы клуба

В настройках игры выберите клуб, укажите:
- основной и дополнительный цвета;
- описание ткани, узора, воротника, рукавов и общей стилистики.

Например: `чёрная соревновательная футболка; ярко-зелёные панели на плечах; тонкие геометрические линии; матовая ткань с аккуратными швами`.

Запрос просит модель менять только футболку и сохранять лицо, волосы, позу, руки, фон и освещение. Но обычная генеративная модель **не гарантирует пиксельное сохранение личности** и может допустить артефакты. Проверяйте результат. Оригинал всегда остаётся резервом. Точный логотип и спонсорские надписи лучше накладывать отдельным графическим слоем: AI часто искажает мелкий текст.

## Проверка и устранение проблем

- В браузере `GET http://127.0.0.1:47831/health` должен вернуть `ok: true` и `configured: true`.
- `HF_TOKEN is missing` — проверьте `.env`.
- `SDK is not installed` — в `tools/jerseys` выполните `npm install`.
- `Origin is not allowed` — помощник намеренно принимает только локальный файл (`Origin: null`) и localhost.
- Ошибка модели/провайдера — проверьте токен, права Inference Providers, доступность модели и баланс аккаунта.
- Если портрет вышел неудачным, исходная фотография остаётся доступна; удалите плохой файл из `assets/media/generated-jerseys/` и нажмите ручную генерацию ещё раз.

Помощник слушает только `127.0.0.1` и не публикует порт в локальную сеть. Ключ API не вшит в проект.
