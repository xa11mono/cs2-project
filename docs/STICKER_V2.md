# Sticker generator V2 pilot

Open sticker-preview-v2.html from repo root. Cologne 2026 and Singapore 2026 are pilot art directions; Cologne 2025 uses facets. Six procedural layout families for 2025+; legacy art pre-2025 and coin renderer retained. This is a working SVG pilot, not a pixel-perfect replica of the concept boards. Four stable signature variants per nick recur; material-independent and full nick. Original logo alpha and aspect ratio retained; gold luminance map uses dark and gold. Foil shares Glitter rarity and market price (uniform item selection), preserving combined rarity odds; this is a design choice, not measured drop data. Existing 2025+ art changes intentionally. No save migration. Tests: node tests/sticker-v2.test.js. Full browser and game suite still required.
