# Автосохранение CS2 Manager v64

## Гарантированный слой — IndexedDB

Каждый снимок полного состояния игры записывается в базу `cs2manager_v56_autosave`, object store `settings`:

- `browserAutosave` — актуальный полный JSON payload;
- `browserBackup` — предыдущая полная версия, обновляемая с интервалом не чаще одного раза в 10 минут;
- `lastBrowserBackupAt` — время обновления резервной копии.

Этот слой не требует `window.showDirectoryPicker` и используется также в средах WebView/локального запуска, где API выбора папки не опубликован.

## Дополнительный слой — папка на диске

Когда среда поддерживает File System Access API, пользователь явно выбирает папку. Дескриптор хранится в IndexedDB как `directoryHandle`. Игра обновляет `CS2Manager-Autosave.json` и rolling backup.

Доступ к произвольной папке нельзя выдавать молча: браузер требует явного действия и разрешения пользователя. Если API отсутствует или разрешение отозвано, внутренняя копия продолжает сохраняться.

## Восстановление

Кнопка «Загрузить автосейв» использует файл из выбранной папки, а когда папка не подключена/недоступна — `browserAutosave`, затем `browserBackup`. Восстановление передаётся штатной функции `importData` через `Blob`, поддерживаемый `FileReader`.

## Полный сброс

Модуль `js/core/factory-reset.js` вызывает `v56PrepareFactoryReset` и `v56ClearAutosaveDatabase`. Второй вызов очищает весь object store, включая обе внутренние копии и сохранённый дескриптор папки.
