CS2 MANAGER v79 — исправление зависания старых сохранений

Основные исправления

1) Планировщик параллельных турниров
- При импорте/замене сохранения инвалидируется старый индекс ближайшего события.
- Для сеток старых сохранений проверяются все незавершённые матчи, а не только первый матч в массиве.
- Просроченные матчи в неотсортированных сетках больше не блокируются матчами с будущим временем.
- За один проход обрабатывается не более 8 матчей; оставшаяся очередь продолжается следующим тиком.
- Архивные турниры, у которых все матчи завершены и уже есть победитель, переводятся в конечный статус, чтобы не запускать бесконечные пробуждения.
- Во время догоняющей обработки откладываются тяжёлая перерисовка рейтинга и полный экспорт сохранения. Промежуточный checkpoint записывается не чаще раза в 20 секунд; после очистки очереди выполняется полное сохранение и обновление интерфейса.
- Добавлена диагностика: window.CS2ParallelSchedulerDiagnostics().

2) Производительность VRS
- Для обычного фонового матча больше не клонируются и не пересчитываются все команды дважды.
- После результата пересчитываются две участвовавшие команды.
- Полный пересчёт лиги выполняется при смене игрового дня, изменении массива команд или в точках фиксации турнира, где он необходим.
- Общая Bounty-Offered reference-картина кэшируется по дню и ревизии доходов.
- Диагностика VRS расширена счётчиком полных пересчётов: window.CS2VRSModel.audit().

3) Автосохранение
- Полное автосохранение и IndexedDB snapshot не конкурируют с догоняющей очередью просроченных матчей.
- После завершения очереди автосохранение возобновляется.

Проверки
- 34 регрессионных теста пройдены.
- Все JavaScript-файлы прошли node --check.
- Синтетический тест VRS: 500 фоновых матчей на 120 командах обработаны примерно за 176 мс в Node-среде. Это изолированный тест VRS, не замер полной игры в браузере.
- Полноценный браузерный прогон на пользовательском старом сохранении не выполнялся.

Обновление
- Перед заменой файлов экспортируйте сохранение в JSON.
- Копируйте файлы v79 поверх прежней папки cs2-project.
- Не удаляйте данные Chrome/Edge и IndexedDB.
- Сохраняйте прежний путь к index.html, затем выполните Ctrl+F5.
