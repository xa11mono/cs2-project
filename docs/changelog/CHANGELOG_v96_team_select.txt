CS2 Manager v96 — экран выбора организации (режим менеджера)
==============================================================

Сохранения v95 открываются без миграции: в данных игры ничего не менялось.

БЫЛО
- Выбор клуба — сетка из 40 логотипов с номером места. Ни состава, ни бюджета, ни целей руководства, ни подсказки,
  насколько клуб сложный. Клубы ниже 40-го места выбрать было нельзя. Та же сетка повторялась на странице «Режим игры».

СТАЛО (js/manager/v96-team-select.js, css/v96-team-select.css)
- Экран «Выбор организации» (#/pick): слева список всех 116 клубов, справа досье выбранного.
  • Список: поиск, порядок (рейтинг / сила состава / бюджет / название), регион, сложность; строка — место, логотип,
    название, регион и стиль, сила состава, сложность. Стрелки ↑/↓ двигают фокус и выбор.
  • Досье: шапка (рейтинг, регион, Tier, стиль, стратегия клуба, тренер), сложность словом и делениями, пять ключевых
    цифр, основной состав с фото и силой игроков, сильнейшие карты, цель руководства, сильные стороны и риски.
  • Внизу — «Возглавить клуб»; если клуб уже есть — «Перейти в клуб» с пояснением, что прежний клуб перейдёт ИИ.
- Цели руководства считаются теми же правилами, что и контракт v91: CS2Board теперь отдаёт tourGoal и rankTarget.
- Сложность: места 1–10 «Лёгкая», 11–30 «Средняя», 31–70 «Высокая», 71+ «Вызов».
- Любая страница «Карьеры» без клуба (штаб, события, тренировки, финансы…) открывает этот экран; заголовок оболочки —
  «Выбор организации». В боковом меню «Карьера» появился пункт «Выбор организации».
- Страница «Режим игры»: вместо сетки логотипов — кнопка «Выбрать организацию».
- Вёрстка: 1672 / 1280 / 1024 / 390 px; ширина досье управляет раскладкой (container query). Полоса действия липкая.
- Старая сетка осталась запасным вариантом (noTeamOld), если модуль не загрузился.

ПРОВЕРКА
- tests/v96-team-select.test.js: все страницы карьеры без клуба открывают экран; досье (5 игроков, цели, плюсы, риски);
  выбор на месте; поиск/регион/сложность/сортировка; клавиатура; «Возглавить клуб» берёт клуб и открывает штаб;
  смена клуба возвращает прежний ИИ (история управления); «Режим игры» ведёт на экран; экран не шире окна на
  1280/1024/390; ошибок в консоли нет.
