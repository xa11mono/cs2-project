CS2 Manager v144 — новая архитектура проекта, ускорение перемотки, исправления сохранений и составов

СТРУКТУРА
- 177 скриптов и 48 стилей разложены по доменам вместо папки версий: js/core, data, base, calendar, competition,
  match, radar, rosters, career, awards, media, fan, portal (css — так же). Имена без префиксов версий
  (v84-core-loop.js → js/core/scheduler.js и т. д.; полное соответствие — tools/build/layout.tsv).
- js/boot/manifest.js — единственный список модулей и одна версия BUILD для сброса кэша (раньше 224 тега в
  index.html, у каждого свой ?v=…). Загрузчик js/boot/loader.js.
- Ядро js/core/kernel.js: CS2.patch (явное расширение функций вместо ручных обёрток), CS2.chain/CS2.layers —
  карта слоёв (какой модуль объявил/обернул какую функцию, собирается автоматически), шина событий CS2.on/emit
  (в неё приходят все события игры v29Emit).
- Общий рейтинг js/core/ranking.js (CS2Rank) вместо копий filter+sort.
- Документация: ARCHITECTURE.md (как вносить правки), README.md, docs/LAYERS.md (генерируется).
- Инструменты: npm test (параллельный прогон), npm run analyze, npm run build (релиз в dist/), npm run check.
- Журналы версий перенесены в docs/changelog/, скриншоты — в docs/shots/.

ПРОИЗВОДИТЕЛЬНОСТЬ
- Перемотка в 3–10 раз быстрее (30 игровых дней: 5–21 с → ~2 с). Каждая уступка браузеру ждала следующего кадра —
  60% времени перемотки поток простаивал. Теперь CS2Yield перерисовывает не чаще раза в 50 мс, в остальное время
  уступает мгновенно (MessageChannel); интерфейс при этом держит 40–45 кадров/с. Пять самописных копий «yield frame»
  объединены. В фоновой вкладке перемотка больше не тормозится троттлингом таймеров.
- Встроенные данные вынесены из кода: шрифты стикеров (2,4 МБ base64) — файлами fonts/stickers/*.woff, грузятся
  только при необходимости; контуры кубков — js/data/trophy-arts.js, сжаты без потерь 3,1 → 1,9 МБ; картинки
  кубков — assets/ui/trophies/. Куча JS после загрузки ~30 → ~19 МБ, загружаемый объём 15,2 → 11,1 МБ.
- Веса ролей и коэффициенты силы игрока кешируются до изменения конфига (CS2Config.version).

ИСПРАВЛЕНИЯ
- Сохранение: при закрытии/перезагрузке вкладки браузер мог оборвать запись в IndexedDB — терялись изменения
  последних секунд. Незаписанные ключи теперь дополнительно копируются синхронно, при запуске берётся более свежая
  версия.
- Составы: замена выдуманного игрока реальным шла мимо журнала Roster Engine (сторож UNTRACKED: «ушёл из основы →
  нигде», в долгой симуляции 2 прогона из 3) — теперь запись REPAIR.

ВСЕ ОБЁРТКИ ЧЕРЕЗ ЯДРО
- Все 216 слоёв глобальных функций переведены на CS2.patch (раньше ~150 ручных обёрток десятка разных видов:
  «const old = X; X = function», метки __vNN, копирование свойств, eval-привязки, повторы через setTimeout).
  CS2.chain('имя') показывает весь стек с настоящими файлами слоёв. Миграция — tools/build/codemod-patch.mjs (AST),
  поиск оставшихся — tools/build/find-wrappers.mjs; тест tests/v144-layers.test.js не даёт добавить новую ручную обёртку.
- CS2.swap(имя, временная, fn) — временная подмена на время вызова с восстановлением в finally.
- Исправлено: при ошибке повторного создания турнира «случайные события» оставались выключенными навсегда
  (восстановление присваивало функцию самой себе) — теперь CS2.swap.
- Удалён мёртвый код: три обёртки window.v15AdvanceMinutes (smart-skip, match-sync, parallel-tournaments) ни разу не
  срабатывали — функция объявлена внутри training-calendar.js и глобальной не была.

ТЕСТЫ
