# Импорт баз CS2 Manager v59

## Где найти кнопки

1. Открой игру.
2. В верхнем меню нажми **Ещё → Сейвы и базы**. Та же страница доступна через **Игра → Настройки и сохранения**.
3. В блоке **Сейв и автосохранение** нажми **Выбрать папку для автосейва**. Выбери папку, в которой хочешь держать `CS2Manager-Autosave.json`, и разреши доступ Chrome/Edge.
4. В блоке **Импорт баз составов и турниров** выбери соответствующие JS/JSON-файлы. Можно выделить сразу несколько файлов в одном диалоге.

## Импорт составов и игроков

Импортёр понимает JSON и JS-файлы с объектами:

- `CS2_REAL`;
- `CS2_EMDB_2026`;
- `CS2_ROSTERS`;
- `TEAM_ROSTER_2026`;
- `PLAYER_META_2026`;
- `PLAYER_STATUS_2026`;
- `DEFAULT_TEAMS`;
- `TEAM_REGION_FLAG`;
- `COACHES_2026`.

Можно выбрать раздельные файлы со списком пятёрок, карточками игроков, странами, тренерами и базовыми очками команд за один раз. Импортёр объединит их. JS-код не запускается: из него извлекаются только статические объекты и массивы.

Формат JSON показан в `CS2Manager-rosters-template.json`. Для каждой команды нужны имя и минимум пять игроков. У игрока можно указать `nick`, `realName`, `age`, `country`, `language`, `role`, `skill`, `firepower`, `tacticalIQ`, `clutch`, `utility`. Для команды: `pts`, `country`, `style`, `coach`, `roster`, `bench`.

Галочка **Обновить текущие пятёрки существующих команд** по умолчанию выключена — текущая карьера не будет незаметно перезаписана. Чтобы обновить текущие составы, включи её до импорта. Галочка **Добавлять новые команды** включает добавление новых организаций.

## Импорт турниров

Импортёр понимает `TOUR_DATABASE`, `TOURNAMENT_DATABASE`, `CS2_TOURNAMENTS` и JSON со списком `tournaments[]` либо массивами категорий `major`, `elite`/`s-tier`, `regular`/`tier1`, `tier2`, `tier3`, `academy`, `bounty`, `weak`/`open`.

У каждого турнира можно задать:

- `name`, `tier`, `year`;
- `organizer`, `city`, `country`, `region`, `venue`;
- `format` (`single`, `double`, `swiss`, `gsl`, `bounty`);
- `size`, `prize`, `min`, `max`.

Пример — `CS2Manager-tournaments-template.json`. Импортированные названия и метаданные применяются к ещё не начавшимся событиям и будущим сезонам; сыгранные и активные турниры не перестраиваются.

## Фото, логотипы и трофеи

В проекте предусмотрена статическая медиатека в `assets/media/`:

- `assets/media/teams/` — эмблемы;
- `assets/media/players/` — портреты;
- `assets/media/media-manifest.js` и `media-manifest.json` — соответствия названий сущностей файлам.

Встроенный браузерный раздел «Медиа» также импортирует изображения в IndexedDB браузера; это отдельное хранилище, не папка автосейва. Для статической поставки добавляй файлы в соответствующие каталоги и обновляй manifest.

Поддерживаются PNG, JPG, WEBP, SVG и GIF до 1.5 MB на файл. Примеры понятных имён: `01_Spirit_logo.webp`, `03_FURIA_logo.svg`, `01_Spirit_Andrey 'tN1R' Tatarinovich.webp`. Числовые префиксы, суффиксы `logo`/`portrait` и ник в кавычках распознаются.

## Если база в другом формате

Встроенный импортёр пока не читает напрямую XLSX, CSV, SQLite/DB или архивы ZIP. Не переименовывай их в `.json` — это не конвертация. Пришли исходные файлы (лучше один ZIP с базой турниров и базой составов), и структуру можно будет адаптировать под импортёр без ручной перепечатки.

## Расширенная база турниров HLTV

В `database-templates/CS2Manager-tournaments-HLTV-extended.json` лежит расширенный пул турниров, собранный из предоставленного CSV HLTV. Он включает международные события, региональные серии, локальные турниры и квалификации. Импортировать его можно через тот же раздел **Импорт баз составов и турниров**. Встроенный пул названий уже расширен этой базой, поэтому новые сезоны будут реже повторять одни и те же события.
