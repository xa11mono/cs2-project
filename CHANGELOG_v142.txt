CS2 Manager v142 — паблики (порт ветки v129.3)
Новые файлы: js/manager/v129-pub-posts.js, css/v129-pub-posts.css; подключены в index.html после капсул.
Остальные файлы архива совпадают с текущими или старее (v131+ уже в игре) — не заменялись.

== v129 — паблики в стиле Telegram ==
- Новая страница «Паблики» (#/pubs, вкладка на «Новостях», пункт в меню зрителя): каналы CS2 NEWS и CS3NEWS как в Telegram — список каналов, лента с датами, пост = квадратная карточка + подпись + реакции с числами (свою можно поставить) + просмотры + админ и время + комментарии.
- 15 шаблонов карточек из данных игры: пики карт, история встреч (таблица по годам и серия с портретами), топ-5 по рейтингу/клатчам, худшие/лучшие турниры звезды, статистика команды за сезон, «когда участники выигрывали трофей», цитата, заголовок с портретом; результат со счётом по картам, статистика игрока за матч, «Факт», «Дайджест новостей», сетка плей-офф, цитата на фото.
- Новости пабликов из ленты становятся постами со своей карточкой; ссылка «Подробнее на HLTV» открывает статью.
- Плитки карт нарисованы процедурно (Mirage, Inferno, Nuke, Ancient, Anubis, Overpass, Dust II, Train, Vertigo, Cache).

== v129.1 — новости = лента каналов ==
- «Новости» по умолчанию открываются лентой каналов в стиле Telegram; старый список — вкладка «Список HLTV».
- Каналы: HLTV.org (с галочкой), CS2 NEWS, CS3NEWS, CS Инсайды (слухи). Каждая новость игры — пост своего канала (≈150 постов вместо ≈40).
- Новые шаблоны по образцам: новость с плашкой рубрики, «Факт» с заголовком сверху, статистика за карту (3 плитки), убийства/смерти крупными цифрами, цитата с именем на плашке, опрос про-игроков; силуэт «источника» у инсайдов.
- Статистика игроков считается по каждой карте (и для идущих матчей) — посты после каждого заметного матча.
- Посты-ответы (ссылка на пост с результатом), «изменено», платные ⭐-реакции, анимации появления, «вниз» к новым постам, подсветка при переходе.

== v129.2 — паблики внутри обычных новостей ==
- Отдельный «Telegram» убран: «Новости» — обычная лента, но каждая новость — пост своего портала; превью новости = карточка поста (старые обложки с наложениями заменены).
- Закреплённые сообщения пабликов (дайджест дня, расписание, свежая инфографика) — вверху «Новостей» и на «Главной», выглядят как сообщение в Telegram (картинка, подпись, реакции, просмотры, комментарии).
- В статье — пост канала как сообщение Telegram, с ответом на исходный пост и комментариями болельщиков.
- Порталы: HLTV.org, Кибер Хроника, CS2 NEWS, CS3NEWS, FragNews (аналитика), CS Insider (слухи), Эко-раунд (мемы). Источник выбирается по рубрике; у каждого свой стиль подписи; слухи иногда с «намёком игрока на стриме».
- Новые шаблоны: дайджест дня с датой и репликой, «Матчи дня» с временем, топ-7 строками (урон/рейтинг), «Факт» CS2 NEWS.
- Чистка ленты: однотипные новости одного дня перефразируются; противоречащие новости про одну команду («на волне» и «в кризисе» в пределах 2 дней) — остаётся свежая.

== v129.3 — превью новостей ==
- Превью в ленте новостей и на «Главной» — компактная карточка: фон-узор (градиенты, полосы, точки, сетка, диагональ) в цвете команды или канала, портрет целиком внутри рамки, логотип команды, значок портала, рубрика. Фото-сцены больше не используются.
- В карточках пабликов фото-сцены тоже заменены на эти фоны; длинные заголовки уменьшаются и не наезжают на подпись.
