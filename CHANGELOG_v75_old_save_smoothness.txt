CS2 Manager v75 — устранение лагов на старых многосезонных сохранениях

- Главная причина тяжёлых пауз: пересохранение локального архива турниров было O(n²). Для каждой записи сериализовался весь растущий объект кэша. Теперь размер новых записей считается отдельно, JSON кэш формируется один раз — проход линейный после сортировки.
- Архив получил журнал изменений по ID. Периодические потребители могут получать только изменившиеся турниры вместо копирования всего архива.
- Выплаты призовых Tier-2/Tier-3 проверяются по ревизии архива и инкрементальному списку изменившихся записей; при отсутствии изменений выполняется O(1) выход.
- Маркер выплаты v31paid теперь сохраняется в записи архива, чтобы исключить повторные выплаты после перезагрузки.
- Рекомендации буткемпа больше не инициализируют playerLayer у сотен старых команд ради read-only отображения.
- Сохранены предыдущие оптимизации v74: кэш статистики архива, более редкие полные обновления интерфейса и отложенная сериализация.
- Никакие матчи, турниры, архивные записи или игровые события этим патчем не удаляются.
